## What Is MQGT-SCF?

MQGT-SCF (Merged Quantum Gauge and Scalar Consciousness Framework) is a **constraint lab**—a computer tool that tests a scientific hypothesis against real experimental data.

Think of it like a "hypothesis testing machine": you feed in a theory, the machine checks it against experiments, and it tells you whether the theory is ruled out, could be detected soon, or is safely below current experimental sensitivity.

---

## What Does It Do?

The framework tests the idea that there might be **new physics** beyond what we currently know. Specifically, it asks:

**"Could there be new forces or fields that affect quantum mechanics, and would we be able to detect them?"**

To answer this, the tool:
1. Takes a theoretical model (new physics proposal)
2. Compares it against experimental data (from particle accelerators, gravity experiments, quantum randomness tests)
3. Reports where the theory would be **excluded**, **near-detectable**, or **safe** from current experiments

---

## What Does It NOT Claim?

**Important:** This framework does **NOT** claim:
- That new physics has been discovered
- That consciousness fields exist
- That any experimental deviations have been observed
- That the theory is correct

It simply says: **"IF this theory were true, here's where we'd expect to see it, and here's where current experiments rule it out."**

Think of it like a treasure map that says "if treasure exists, it would be in these locations"—but we haven't actually found the treasure yet.

## How Does It Work? (Simple Version)

### The Basic Idea

The framework proposes that quantum measurement might be influenced by:
- **Consciousness fields:** Physical fields that relate to subjective experience
- **Ethical fields:** Physical fields that relate to moral values

This would mean quantum probabilities (the "randomness" in quantum mechanics) might be slightly biased toward "good" or "conscious" outcomes.

### Testing the Idea

To test this, the framework:
1. **Predicts where effects would appear:** If these fields exist, they'd show up as deviations in:
   - Quantum random number generators (QRNGs)
   - Short-range gravity tests (fifth-force experiments)
   - Particle physics experiments (Higgs decays)

2. **Compares to real data:** Uses actual experimental results to see if any deviations are observed

3. **Reports results:** Says "no deviations observed in hunt band X" or "theory ruled out by experiment Y"

### Current Results (Simplified)

- **QRNG tests:** No significant biases observed (bound: ε < 0.01)
- **Fifth-force tests:** Theory not ruled out in mm-cm range (hunt band identified)
- **Particle physics:** Consistent with Higgs measurements (within experimental uncertainty)

**Bottom line:** The theory hasn't been detected, but it also hasn't been ruled out in certain parameter ranges.

## The "Constraint Lab" Approach

### Why Call It a "Lab"?

Unlike traditional theoretical physics papers, this work:
- **Includes code:** Computer programs that anyone can run
- **Uses real data:** Actual experimental results, not just theoretical calculations
- **Is reproducible:** Anyone can download and run the analysis
- **Is falsifiable:** Makes clear predictions that experiments can test

### What Makes It "World-Grade"?

The framework follows best practices:
- **Frozen inputs:** All data files have cryptographic hashes (SHA256) to prevent tampering
- **Explicit assumptions:** All assumptions about mappings and parameters are documented
- **Robustness checks:** Tests how results change when assumptions are varied
- **Automated reproduction:** One command (`make reproduce`) reproduces all results
- **Layered publishing:** Results published in layers (safe claims first, speculative claims later)

## Key Takeaway

MQGT-SCF is **not** a validated discovery. It's a **constraint lab**—a tool for testing hypotheses against experiments. It makes testable predictions, uses real data, and follows best practices for reproducibility. Whether the hypothesis is correct remains to be determined by future experiments.

**The real value:** It demonstrates how to do rigorous speculation in science—with clear assumptions, reproducible methods, and falsifiable predictions.
